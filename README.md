# Studio Morrow

Marketing site for a brand and content studio. Astro + Tailwind, fully static.

- `npm run dev`: local preview
- `npm run build`: production build into `dist/`
- `npm run images`: regenerate the placeholder imagery in `public/images`

All copy lives in `src/data/site.ts`. Replace the files in `public/images` with real photography (same names) when ready.
